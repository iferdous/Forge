## Cross-stage verification

- **Current benchmark snapshot.** Ubuntu 24.04 and Windows Server 2025 x64 each passed 23 CTest entries and all 61 benchmark-case validations at source commit 4a1620b. The README timing tables and charts use that run's harness output. The CI page tracks validation of later commits on main. [Benchmark CI and artifacts](https://github.com/iferdous/Forge/actions/runs/45268500878) · [CI on main](https://github.com/iferdous/Forge/actions/workflows/ci.yml?query=branch%3Amain)
- **Recorded native examples.** The seven published AVX2 traces and isolated RSS experiment are from the Ubuntu x64 run at 5e04a53. [Trace CI and artifacts](https://github.com/iferdous/Forge/actions/runs/45124189095)
- **Apple Silicon.** The M3 executed the scalar JIT and verified x86-64 code emission. Of 23 CTest entries, 22 passed and the native AVX2 tail guard test skipped on this host. Linux and Windows x64 executed that path.
- **Sanitizer coverage.** Linux x64 at 4a1620b passed 20 ASan/UBSan CTest entries. First-party C++ coverage held at 869 of 919 lines (94.56%) and 291 of 342 branches (85.09%). The documented vptr and indirect function exclusions apply. Separate guard tests exercise JIT buffer edges. [Hardening scope](plan/08-release-and-handoff.md#hardening-scope) · [Benchmark and sanitizer CI](https://github.com/iferdous/Forge/actions/runs/45268500878)
- **Evidence integrity.** The chart generator verifies the archived raw evidence against a SHA-256 manifest before rendering. The tagged preview supplies timing for the published films. [Current evidence archive](../showcase/data/benchmark-evidence.zip) · [Preview evidence](https://github.com/iferdous/Forge/releases/tag/v0.1.0-preview.1) · [Measurement report](results.md)

## Refined acceptance brief

A visitor should be able to run or inspect a genuine example within one click from the README, follow it from expression to native instructions, and see the corresponding output. Each chart must identify its workload, timed boundary, source commit, and provenance. Animation of a loop, memory movement, or vector lanes must be distinguishable from hardware counters and native output. Retain numerical checks, show regressions and performance losses, and provide the commands and input files required to regenerate the results. The preview qualification stays open until an idle native x64 host runs the controlled profile.
