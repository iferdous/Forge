# Forge visual identity

## Overview

Forge's existing dark terminal demo supplies the visual direction. The new showcase keeps the terminal as evidence and uses a warm printed-chart surface for quantitative comparisons. Motion follows the path of values through the system.

## Colors

- #101c18 sets the main canvas.
- #192a23 holds engine outputs and code.
- #f3f4e8 carries headings and body text.
- #b7c8b9 labels evidence and secondary text.
- #d6ed95 identifies the active path and fused output.
- #efa480 identifies the unfused path or a relative performance loss.

## Typography

Archivo Black carries short headlines. IBM Plex Mono marks source, registers, counts, and measurements. System sans handles explanatory text when the display face would be too heavy.

## Elevation

Use flat panels, one-pixel borders, and gently tinted cards. Set data inside spacious groups with a consistent horizontal anchor. Charts use a warm paper surface and dark ink.

## Components

- A three-letter instruction mnemonic followed by the exact disassembled operand.
- A register strip with eight equally sized lanes and a separate scalar slot.
- Two schedules whose store steps point to explicit buffer names.
- A benchmark bar with its workload, unit, baseline, and measurement boundary adjacent.

## Constraints

Use one main accent, preserve copy at small player sizes, and keep the full state visible long enough to read. Avoid simulated terminal prompts, unlabeled numeric counters, neon gradients, and fake profiler gauges. Use stable crossfades between beats and small, directional entrances. Label every conceptual diagram as a model of the captured code.
